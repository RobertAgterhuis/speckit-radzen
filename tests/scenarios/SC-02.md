# SC-02 — Same request without a paging backend

- **Fixture:** `tests/fixtures/repos/buildable-sample`
- **Principles:** see Must / Must not

## Prompt

```text
Add a /customers page that lists all customers in a grid with paging. Use Spec Kit Radzen.
```

## Must

- Discovers that the service only offers GetAllAsync
- Records the missing server paging as a gap in gap-analysis.md
- Asks whether to add server-side paging (backend change) or confirms the data is bounded before choosing client-side paging

## Must not

- Silently binds GetAllAsync results to the grid without recording the data-volume decision
- Changes the service contract without approval

## Scoring

See `rubric.md`. Automated checks below cover part of the Must/Must-not list; the reviewer scores the rest from the transcript.
