# Workflow: Specify
1. Express the requirement as observable behavior.
2. Identify actors and authorization context.
3. Define functional outcomes.
4. Define relevant responsiveness, accessibility, data-volume, performance, localization, and security constraints.
5. Record non-goals.
6. Perform capability/gap analysis.
7. Separate facts, assumptions, and unknowns.
8. Avoid premature implementation choices unless intrinsic to repository constraints.

Output: use `templates/feature-spec.md`.
