# Workflow: Review
Review against the requirement, not merely the diff.

Check architecture preservation; Radzen API correctness and component choice; server-side authorization; data minimization; loading/empty/error/validation/forbidden/read-only states; responsive behavior; keyboard/focus/labels; credible performance concerns; build/tests/analyzers; and unexplained warnings or architecture drift.

Finish with `checklists/definition-of-done.md`.
