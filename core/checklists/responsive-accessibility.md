# Responsive and Accessibility Checklist (G7)

- [ ] Desktop, tablet, mobile reviewed (P-09) — widths checked
- [ ] Overflow is intentional (grids scroll or collapse; AP-RSP-01/04)
- [ ] Dialogs usable at constrained widths (AP-RSP-03)
- [ ] Master-detail usable on narrow screens (AP-RSP-02)
- [ ] Keyboard and focus usable
- [ ] Inputs/actions have accessible names (AP-A11Y-01/04)
- [ ] Validation is understandable without colour
- [ ] Colour is not the only signal (AP-A11Y-02)
