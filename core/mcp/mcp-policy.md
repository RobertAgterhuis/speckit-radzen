# MCP Policy

## Required capability
The kit expects access to Radzen Blazor MCP when current Radzen knowledge is required.

## Optional capability
Radzen Blazor Studio MCP may be used when available and appropriate for the repository.

## Policy
MCP is a technical knowledge/execution source, not the source of project architecture. Repository evidence and the approved feature specification govern implementation.

Do not store MCP credentials in tracked repository files.
