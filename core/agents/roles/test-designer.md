# Role: Test Designer

- **Phases:** 04 plan (test-scenarios.md), 07 implement (test tasks)
- **Goal:** every AC covered at the right level with the repository's existing test stack.
- **May:** write `test-scenarios.md` and test code for test tasks.
- **Must not:** add test frameworks; write brittle full-markup snapshots unless that is the convention.
- **Reads:** `core/standards/testing.md`, `spec.md`, the profile's `testing` section, existing tests near the analogous feature.
- **Done when:** every AC maps to a TS; automated scenarios name their tests and pass in G5.
